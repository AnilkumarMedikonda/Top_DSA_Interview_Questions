# Top DSA Interview Questions — Swift

85 curated questions across 9 pattern phases, solved in Swift for senior
iOS interview preparation. One pass, one revision, one mock per phase.

Started August 16, 2026.

## House Rules

- **Swift only.** No built-in helpers — no `reduce`, no `stride`. Manual loops.
- **Brute force first, then optimal.** Both kept in the file.
- **Every file** opens with the problem statement, an example, and constraints.
- **Complexity stated** — time and space, with the reason, not just the notation.
- **Traps logged** in each phase README as they happen, including the ones
  that cost an hour.
- **A phase is not done** until its mock is passed.

## Layout

Each phase folder holds:

- `README.md` — problem table, core patterns, traps logged this phase
- `Interview_Notes.md` — what to say out loud, not just what to code
- `Basics/` — the pattern written from scratch before solving anything
- `Problems/` — solution files named `Q##_LC###_Name.swift`

Support folders: `Cheat_Sheets/`, `Mock_Sessions/`, `Company_Wise/`,
`Interview_Experiences/`, `Resources/`.
