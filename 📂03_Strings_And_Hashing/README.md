# 📂 Phase 03 — Strings & Hashing

## 🎯 Goal

Master the most common **String** and **Hashing** interview patterns used in coding interviews. This phase focuses on solving problems efficiently using **HashMap**, **HashSet**, **Character Frequency**, **Sorting**, and **String Traversal** techniques.

By the end of this phase, you should be able to recognize the correct pattern within a few seconds and implement the optimal solution confidently in Swift.

* Character Frequency Counting

* Sorting Strings
* Frequency Signature
* Vertical Scanning

* Two-Map Bijection
* Two Pointers on Strings

# 🧩 Patterns You'll Learn

| Pattern                 | Purpose                                  |
| ----------------------- | ---------------------------------------- |
| HashMap                 | Fast key-value lookup and counting       |
| HashSet                 | Constant-time existence checks           |
| Character Frequency     | Count occurrences efficiently            |
| String Traversal        | Iterate through strings correctly        |
| Two Pointers on Strings | Compare characters from both ends        |
| Word Splitting          | Process words separated by spaces        |
| Vertical Scanning       | Compare strings column by column         |
| Sorting Strings         | Normalize strings for comparison         |
| Frequency Signature     | Build unique keys using character counts |
| Bucket by Frequency     | Group values by occurrence count         |
| Two-Map Bijection       | Maintain one-to-one mappings             |
